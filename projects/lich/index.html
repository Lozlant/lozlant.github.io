概览

愿景：玩家在混乱战斗中享受朋友之间互相使坏的快乐：偷偷背刺得逞时的得意，被背刺时的哭笑不得，以及一局结束后的互相「控诉」。

每位玩家都是一名掌握独有元素的亡灵法师。大家有着共同的目标：把闯进黑魔法景区的教会赶出去。但和谐友爱是不存在的——敌人的灵魂固然是施法的必需品，队友的灵魂却更加强大。

在战斗的关键时刻，背刺你的队友，甚至炸飞他的项上人头吧：更强的攻击、更多的灵魂，都将属于你。又或者，做出一点牺牲，把你的灵魂和力量暂时分享给队友。别担心，伟大的亡灵法师只要让自己的头找回身体，就能复活。

设计挑战

如何让玩家在合作战斗中主动选择互相攻击，并享受背刺、合作、策略与混乱的乐趣？

  • 一切以笑声收场：无论是战斗、互相攻击还是死亡，带来的都是欢乐，而不是互相埋怨。
  • 无负担，有回报：攻击队友不伤感情，还能为自己和全队带来好处。
  • 人人都有用武之地：不同水平的玩家，都能找到自己帮助队伍的方式。

玩法

Project Lich 是一款 3D 俯视角的 3 人合作魔法战斗游戏。

  • 推进：玩家在名为「黑魔法景区」的场景里前进，击退所有敌人。
  • 灵魂：施法需要消耗灵魂，击败敌人就能获得更多灵魂。
  • 攻击队友：攻击或击杀队友会触发元素反应，获得更强大的攻击能力。
  • 死亡：死亡的玩家会掉落持有的灵魂，变成头颅；变成头颅后仍然可以抢夺灵魂，回到身体就能复活。

核心循环

  1. 战斗
  2. 获得灵魂
  3. 施法
  4. 击败敌人
  5. 回到战斗

死亡循环

  1. 战斗中死亡
  2. 头颅飞出
  3. 找回身体，沿途抢灵魂
  4. 复活
  5. 回到战斗

系统一览

  • 灵魂资源系统灵魂是施法资源：怎么获得、持有、拾取与争夺。
  • 合作战斗与友军伤害核心玩法：攻击队友是有得有失的策略。
  • 攻击队友的奖励对队友造成伤害时，双方各获得一次元素反应攻击；击杀队友引发元素反应爆炸。
  • 死亡与复活死亡不是出局：变成头颅，仍可争夺灵魂，复活后回到战斗。
  • 元素每位玩家有一种独有元素。
  • 战斗波次一次战斗由 2 到 3 波敌人组成：刷出、定时与提前清空、战斗结束。
  • 敌人 AIPoC 只有一种发射法球的敌人。
